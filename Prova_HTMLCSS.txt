 

 Para fazer com que fique 2 colunas em cima e 2 colunas em baixo em row

CSS
	display: grid;
 	grid-template-columns: 1fr 1fr;


Para saber o máximo que pode ir de largura e comprimento

CSS
	Max-width e max-height

Isso faz com que o padding e a border não aumentem o tamanho total da caixa, facilitando o cálculo de layout.

CSS
	box-sizing: border-box;

Para deixar em Negrito

CSS
	font-weight: bold;

Junta flex-direction + flex-wrap

CSS
	flex-flow: row wrap;
