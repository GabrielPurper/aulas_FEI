# 📁 Formatos_arquivos

Pasta destinada a arquivos soltos que foram organizados e não possuem uma categoria específica no repositório.

## Conteúdo:
- **Geogebra_Imagem2.png** - Imagem do software Geogebra (versão 2)
- **Geogebra_imagem.png** - Imagem do software Geogebra
- **Prova_HTMLCSS.txt** - Arquivo de texto com prova de HTML/CSS
- **Prova_HTMLCSS_NEW.txt** - Versão atualizada da prova de HTML/CSS
- **servidor.js** - Arquivo JavaScript para servidor Node.js
- **Texto_Atividade** - Documento com texto de atividade
- **node_modules.zip** - Dependências do projeto Node.js (não recomendado manter versionado)
- **Servidor.zip** - Arquivo compactado com configurações do servidor
- **Servidor (2).zip** - Versão anterior do servidor compactado
- **ServidorProvaCarros.zip** - Servidor com prova de carros
